## 게임 컨셉
**1(도깨비) vs 다수(활잡이)** 비대칭 술래잡기 액션 게임입니다.  
도깨비는 제한 시간 동안 활잡이들을 따돌리며 생존해야 하고,  
활잡이 팀은 제한 시간 안에 도깨비를 처치해야 합니다.
## 승리 조건
### 도깨비 팀 (1인)
- 제한 시간 종료 시까지 생존하면 승리
### 활잡이 팀 (다수)
- 제한 시간 내 도깨비 처치 시 승리
## 게임 목표
- **도깨비:** 이동/회피/심리전으로 활잡이의 공격을 유도하고 끝까지 살아남기
- **활잡이:** 팀 단위로 포지션을 나눠 도깨비를 포위하고 집중 사격으로 처치하기
## 게임 플로우
1. **매치 시작**
   - 1인은 도깨비, 나머지는 활잡이로 배정
   - 제한 시간과 기본 UI(체력, 타이머) 활성화
2. **추격전 진행**
   - 도깨비: 회피/유인/거리 관련 스킬을 활용하여 생존 시도
   - 활잡이: 광역스킬/추적/협공으로 도깨비 압박
3. **전투 판정**
   - 피격/체력 감소/상태 갱신
4. **라운드 종료**
   - 타이머 종료 → 도깨비 승리
   - 도깨비 처치 → 활잡이 승리
5. **다음 라운드**
   - 역할 재배정 또는 동일 역할로 재시작
